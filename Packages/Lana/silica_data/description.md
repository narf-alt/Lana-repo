# Lana

Lana is a premium iOS theme inspired by the warmth and texture of handcrafted wool.

Every detail is designed to give your Home Screen a soft, distinctive visual identity, with custom icon artwork and a consistent textile-inspired aesthetic.

### Features

- Soft wool-inspired visual style
- Carefully crafted custom icon designs
- iOS 15–26 support
- Regular updates and improvements
- More icon support added over time
- Premium edition
