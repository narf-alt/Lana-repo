WCLocate

微信虚拟定位插件，在越狱环境下为微信提供可配置的虚拟位置能力。

功能

  • 地图选点 — 在地图上直接选择目标位置
  • 地点搜索 — 按关键词搜索并快速定位
  • 拖拽定位 — 拖动标记微调坐标
  • 海拔伪装 — 同步模拟海拔信息
  • 坐标纠偏 — 自动处理国内坐标偏移

使用说明

安装后在「设置」中找到 WCLocate，开启功能并按提示选择位置。修改定位后建议重启微信使配置生效。
